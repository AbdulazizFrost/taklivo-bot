# 💍 TAKLIVO — Telegram-бот для продажи свадебных онлайн-приглашений

Production-ready Telegram-бот на Python (aiogram 3.x) для автоматизации продаж и создания персональных цифровых свадебных приглашений.

---

## 🛡 Гарантия сохранности данных (Память заказов)

1. **База данных SQLite в режиме WAL (`PRAGMA journal_mode = WAL;`):**
   * Все заказы, клиенты, фото и чеки записываются на диск в реальном времени.
   * Никакие данные не пропадут при перезапуске бота или перезагрузке сервера.
2. **Встроенное резервное копирование (Backup):**
   * В панели администратора `/admin` добавлена кнопка **«💾 Скачать бэкап БД»**.
   * При нажатии бот моментально создает снимок базы и присылает файл `.db` вам прямо в Telegram!
   * Автоматические копии также сохраняются в директории `data/backups/`.

---

## 🚀 Развертывание на сервере (VPS / Cloud)

### Вариант 1. Через Docker Compose (Рекомендуется — в 1 команду)
1. Склонируйте репозиторий на сервер (Ubuntu/Debian):
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ> taklivo_bot
   cd taklivo_bot
   ```
2. Создайте файл `.env` с вашими данными (`BOT_TOKEN`, `ADMIN_ID`, `PAYMENT_DETAILS`):
   ```bash
   nano .env
   ```
3. Запустите через Docker Compose:
   ```bash
   docker compose up -d --build
   ```
   *Папка `data/` примонтирована как Persistent Volume — ваши заказы сохранятся навсегда.*

---

### Вариант 2. Автоматический запуск через скрипт (Systemd)
1. Дайте права на запуск скрипту деплоя:
   ```bash
   chmod +x deploy.sh
   ./deploy.sh
   ```
2. Скрипт сам создаст виртуальное окружение, установит зависимости и настроит автозапуск службы `taklivo.service` при перезагрузке сервера.

---

## ⚙️ Управление службой на сервере (Systemd)

* **Проверить статус:** `sudo systemctl status taklivo`
* **Посмотреть логи:** `sudo journalctl -u taklivo -f`
* **Перезапустить:** `sudo systemctl restart taklivo`
* **Остановить:** `sudo systemctl stop taklivo`
